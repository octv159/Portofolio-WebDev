# Bayucaraka ITS — UAV Research Team Profile Landing Page

Landing page profil resmi **Bayucaraka ITS** (Tim Riset Pesawat Tanpa Awak / UAV UKM Robotika Institut Teknologi Sepuluh Nopember) yang dibangun menggunakan **HTML5 semantik** dan **CSS3 murni** tanpa framework maupun JavaScript. Proyek ini disusun untuk memenuhi *Special Task* Open Recruitment Staff Web Development Bayucaraka ITS 2027.

## Fitur & Struktur Halaman
1. **Navbar & Live Telemetry Ticker:** Menampilkan logo institusi (ITS, UKM Robotika, Bayucaraka), menu navigasi *sticky*, serta pita teks bergerak otomatis mengenai pencapaian terbaru tim.
2. **Hero Section & Radar HUD:** Bagian pembuka bergaya *Cyber-Aerospace HUD* lengkap dengan animasi radar pemindai dan metrik tim yang dibuat murni menggunakan CSS `@keyframes`.
3. **About Us & Sanskrit Philosophy:** Penjelasan sejarah tim sejak 2014 serta filosofi akar kata Sanskerta *Vāyu* (Udara) dan *Caraka* (Pengembara) dalam kartu simetris.
4. **Six Specialized Divisions:** Tata letak *CSS Grid* 3x2 yang merinci enam divisi utama (*Racing Plane, Fixed Wing, LELA, VTOL, Technology Development*, dan *Official Division*).
5. **Interactive Achievements (Pure CSS Tabs):** Sistem tab interaktif berbasis *radio input* dan selektor `:checked` tanpa JavaScript untuk menelusuri rekam jejak juara di ajang **KRTI**, **SAFMC Singapura**, dan **TEKNOFEST TÜBİTAK**.
6. **Footer & Contact:** Tautan resmi media sosial dan situs web Bayucaraka ITS.
